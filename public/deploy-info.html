การเข้าใช้บนเซิร์ฟเวอร์

สำหรับผู้ประสานงานและ IT

ที่อยู่เข้าใช้งานของคุณตอนนี้

—

คนอื่นเข้ายังไง

  1. ต้องเข้าถึงเครือข่ายเดียวกับเซิร์ฟเวอร์ (LAN / VPN / IP ที่ IT เปิด)
  2. เปิดเบราว์เซอร์ แล้วพิมพ์ http://<IP-เซิร์ฟเวอร์>:8080/ (หรือพอร์ตที่ตั้งใน Docker)
  3. เริ่มที่หน้าแรก แล้วเลือกเมนู เช่น 「สร้างรายการเบิกใหม่」「ตั้งค่าระบบ (Admin)」

ข้อจำกัดที่ควรรู้

  • •ข้อมูลอยู่ในเบราว์เซอร์: หมวดงบจากแอดมิน โปรไฟล์ และรายการเบิก (เมื่อไม่มี API) เก็บใน LocalStorage ต่อเครื่อง — ไม่ใช่ฐานข้อมูลกลางบนเซิร์ฟเวอร์
  • •กติกาเดียวกันทั้งทีม: ให้ฝ่ายการเงิน (หรือผู้กำหนด) ตั้งค่าแอดมินบนเครื่องหนึ่ง แล้วถ่ายโอนค่าไปเครื่องอื่นตามขั้นตอนที่องค์กรกำหนด (หรือรอฟีเจอร์ export/import ในอนาคต)
  • •ไม่มีระบบ login ในแอปนี้ — ใครรู้ URL ก็เข้าได้ ควรใช้ในอินทราเน็ตหรือจำกัดไฟร์วอลล์
  • •คีย์แผนที่ Longdo อยู่ในโค้ดหน้าเว็บ — หากเปิดสู่สาธารณะควรปรับตามนโยบายความปลอดภัย
  • •HTTPS: แนะนำให้ IT ใส่ reverse proxy (เช่น TLS ที่ Nginx/Caddy ด้านหน้า) สำหรับใช้งานจริงในองค์กร
